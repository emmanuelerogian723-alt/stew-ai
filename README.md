# 🍲 Stew Code

The zero-dependency AI coding agent for the terminal. Built in Nigeria 🇳🇬

`npm i -g stew-ai` · 50KB · 0 dependencies · Node 18+

## Quick start

```bash
npm i -g stew-ai
stew register --name "You" --email you@mail.com --password pass123
stew code
```

## Commands

`stew code` AI coding REPL · `stew chat <msg>` chat · `stew agent <task>` autonomous agent · `stew marathon <goal>` hours-long runs · `stew search <q>` web search · `stew scrape <url>` scrape · `stew crawl <url>` crawl sites · `stew api <METHOD> <url>` REST/GraphQL · `stew skills` list skills · `stew status` API status
stew browse <url>        # interactive web automation (click links, fill forms, cookies)
stew screenshot [url]    # capture a web page (headless Chrome) or your screen
stew record [secs]        # record your screen (screencapture/ffmpeg)

## In the REPL

`/browse open <url> · click · forms · fill — interactive browsing with cookies · /screenshot [url] · /record <secs> screen capture · /build <prompt>` ship an app from a prompt — plans, writes, verifies, fixes, installs, commits · `/swarm <task>` multi-agent team (planner + parallel workers) · `/explain <q>` ask how the codebase works · `/review` AI code review · `/image <path>` vision — ask about screenshots · `/voice on` spoken responses · `/mcp add <n> <cmd>` MCP servers · `/changelog` CHANGELOG.md · `/fix` `/test` `/doc` `/scan` `/sh <cmd>` guarded shell · `/undo` revert last change · `/git` `/model` `/persona` `/plan` `/web` `/save` `/load` · STEW.md project memory · Drop a `STEW.md` in your repo with rules — Stew reads it every session and remembers fixes that worked.
