Capabilities

Everything the paid tools have.
Minus the price tag.

Stew Code reads and writes files, runs shell commands, searches the web, verifies its own output, and forges new skills for itself. All in a package smaller than one Cursor icon.

🤖

AI Coding Assistant

Chat with AI in your terminal. 6 providers (Groq, Mistral, NVIDIA, OpenRouter, HuggingFace, OpenAI) with automatic failover, streaming responses, multi-line input, 12 personas.

🔬

Security Scanner

Scan for hardcoded secrets, API keys, passwords, injection vulnerabilities, phishing patterns, and malware indicators. 20+ pattern matchers, LOW→CRITICAL threat scoring.

✅

Self-Verification

3-pass verification on every write: syntax check, logic review, security audit. If something fails, it auto-retries with fixes up to 3 times.

🏃

Marathon Mode

Give it a goal and let it run for hours. It plans, executes, checkpoints to disk, and self-heals. Kill the terminal, come back tomorrow — it resumes where it left off.

🔨

Skill Forge

When Stew hits a task it can't do, it writes a new skill for itself and uses it immediately. 17 built-in skills + unlimited custom. No plugins, no marketplace.

🌐

Web Search + Scraper

Paste a URL and Stew reads the page before answering. Full scraper and crawler — extract clean text, links, metadata. No API key needed.

🌍

Dev Environment Setup

One command configures your whole environment. /setup vscode creates settings, launch, tasks & extensions. /setup opencode for OpenCode. /setup all does everything + .editorconfig.

🎭

12 Personas + Mascot

Developer, doctor, lawyer, analyst, architect, comedian and more — each with specialized prompts. Plus an ANSI mascot that reacts to what's happening. Because coding should be fun.

Get started

Running in under a minute

 install & launch
# Install (Node 18+)
npm install -g stew-ai

# Launch the AI coding REPL
stew code

# Or use individual commands
stew scrape https://example.com
stew api GET https://api.github.com
stew marathon "Build a REST API with tests"
