Why Stew Code Exists

The Problem

Most AI coding tools — GitHub Copilot ($10/month), Cursor ($20/month), Tabnine ($12/month) — are priced for Silicon Valley salaries. A developer in Lagos, Abuja, or Enugu earning in Naira can't justify $20/month for a coding assistant.

The Solution

Stew Code is a terminal-based AI coding agent that costs nothing to install and runs on any laptop with Node.js 18+. No subscriptions. No credit card. No bloat. Just raw coding power in your terminal, built by a Nigerian developer who understands the struggle.

The Mission

Give every African developer world-class AI coding tools — for free. No paywalls, no gatekeeping, no "Pro tier" for basic features. The code is open source. The community owns it.

What Stew Code Can Do

🤖 AI Coding Assistant

Chat with AI in your terminal. Read/write files, run shell commands, search the web. Supports 6 AI providers (Groq, Mistral, NVIDIA, OpenRouter, HuggingFace, OpenAI) with automatic failover. Streaming responses, multi-line input, 12 personas.

🔬 Security Scanner

Scan your codebase for hardcoded secrets, API keys, passwords, injection vulnerabilities (eval, exec, innerHTML), phishing patterns, and malware indicators. 20+ pattern matchers with threat scoring from LOW to CRITICAL.

✅ Self-Verification

Stew Code verifies its own output. After writing code, it runs 3-pass verification: syntax check, logic review, and security audit. If something fails, it auto-retries with fixes up to 3 times.

🏃 Marathon Mode

Give Stew Code a goal and let it run for hours. It plans, executes, checkpoints to disk, and self-heals on errors. Kill your terminal, come back tomorrow — it resumes exactly where it left off.

🔨 Skill Forge

When Stew Code encounters a task it can't do, it writes a new skill for itself and starts using it immediately. No plugins. No marketplace. Just self-improvement. 16 built-in skills + unlimited custom skills.

🌍 Dev Environment Setup

One command sets up your entire dev environment. /setup vscode creates VS Code config files (settings, launch, tasks, extensions). /setup opencode creates OpenCode config. /setup all does everything + .editorconfig.

🕷️ Web Scraper & Crawler

Scrape any URL or crawl entire websites. Extract clean text, links, and metadata. No API key needed. Perfect for data collection, research, and competitive analysis.

🔌 API Caller

Call any REST or GraphQL API from the terminal. Custom headers, JSON bodies, query parameters, bearer auth. Built-in curl-style flag parsing.

🎭 12 Personas

Switch between developer, doctor, lawyer, consultant, researcher, writer, teacher, analyst, architect, designer, marketer, and comedian modes. Each with specialized system prompts.

🎭 Mascot

Stew Code has a face. ANSI art that reacts to what's happening: thinking, working, success, error, and marathon states. Because coding should be fun.
